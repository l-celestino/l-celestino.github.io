Política de privacidade — assistente-nd

O assistente-nd é um app pessoal, usado apenas pelo dono da conta Google que o autorizou.

  • O que acessa: as listas e tarefas do Google Tasks do próprio dono, para mostrar as pendências dele e marcar como feitas as que ele concluir.
  • Onde fica: a autorização e os dados ficam só no computador e no servidor privado do dono.
  • Compartilhamento: nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • Como revogar: a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Contato: pelo e-mail de suporte exibido na tela de autorização do Google.
